# Початкове налаштування Kali Linux Live USB з Encrypted Persistence

## 1. Оновлення системи

Вимкнути локальний репозиторій оновлень

```bash
sudo sed -i.bak '/^deb .*file:\/run\/live\/medium/s/^/# /' /etc/apt/sources.list
```

```bash
sudo apt update
sudo apt full-upgrade
```

Додати свого користувача до групи wireshark

```bash
sudo usermod -aG wireshark $USER
```

```bash
df -h
sudo apt clean
sudo apt autoremove
```

## 2. Обліковий запис і базовий захист

Змініть пароль облікового запису:

```bash
passwd
```

Перевірте прослуховувані порти та SSH:

```bash
sudo ss -tulpn
systemctl status ssh --no-pager
```

Якщо SSH не потрібен, вимкніть його за наявності служби:

```bash
sudo systemctl disable --now ssh
```

За потреби увімкніть простий firewall (може заважати деяким мережевим лабораторіям):

```bash
sudo apt install ufw
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw enable
sudo ufw status verbose
```

## 3. Встановити часовий пояс

```bash
sudo timedatectl set-timezone Europe/Kyiv
```

## 4. Корисні інструменти

Спочатку перевірте вже встановлені:

```bash
sudo apt install kali-linux-default
```

Для веб-аудиту та діагностики можна точково встановити:

```bash
sudo apt install dnsutils jq python3-venv
```


## 5. Робочі каталоги та термінал

```bash
mkdir -p ~/Security/{Projects,Reports,Captures,Wordlists,Scripts,Tools}
git config --global init.defaultBranch main
```

Для Zsh можна додати аліаси:

```bash
cat >> ~/.zshrc <<'ALIASES'
alias ll='ls -lah'
alias update='sudo apt update && sudo apt full-upgrade'
alias ports='sudo ss -tulpn'
alias localip='ip -br addr'
ALIASES
source ~/.zshrc
```

## 6. Браузер і Burp Suite

1. Запустіть Burp Suite і відкрийте вкладку Proxy.
2. Для HTTPS-перехоплення використовуйте вбудований браузер Burp: він зазвичай простіший для початкового налаштування.
3. Якщо використовуєте зовнішній браузер, налаштуйте проксі (зазвичай `127.0.0.1:8080`) і встановіть CA-сертифікат Burp **лише у виділений тестовий профіль браузера**, а не глобально на всю систему.
4. Після тестування вимикайте проксі та закривайте Burp.

Не використовуйте один і той самий профіль для банківських акаунтів і активного аналізу тестових застосунків.

## 7. Резервні копії LUKS і файлів

**Наступна команда — приклад лише для випадку, коли ви точно переконалися, що зашифрований розділ як і раніше `/dev/sda3`.** Підключіть окремий резервний носій і оберіть дійсний шлях до нього:

```bash
sudo cryptsetup luksHeaderBackup /dev/sda3 \
  --header-backup-file /path/to/EXTERNAL_BACKUP/kali-luks-header.img
```

Заголовок зберігайте окремо і захищено: резервна копія заголовка може містити ключові слоти, тому при компрометації парольної фрази створює додатковий ризик. **Резервна копія заголовка не замінює резервну копію файлів.** Для файлів:

```bash
rsync -aH --info=progress2 ~/Security/ /path/to/EXTERNAL_BACKUP/Security/
```

Шляхи `/path/to/EXTERNAL_BACKUP` замініть на реальну змонтовану директорію *іншого* накопичувача. Періодично перевіряйте відновлення.
