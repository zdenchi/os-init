# Hermes на Orange Pi: один користувач, можливості VPS і ізоляція домашньої мережі

## 1. Результат і межі захисту

Один власник, один агент Hermes, один основний користувач Linux — `adminpi`. Orange Pi працює як звичайний сервер: SSH, Git, браузер, API, встановлення пакетів і запуск застосунків. Команди Hermes виконуються безпосередньо в ОС з правами `adminpi`. Системне адміністрування через sudo виконує власник по SSH.

Домашню мережу захищає Keenetic: Orange Pi може звертатися в інтернет, але не може ініціювати підключення до домашніх пристроїв або керування роутером. Така межа зберігається навіть при зміні firewall на самому Orange Pi. Вона не захищає файли та API-ключі самого Orange Pi від скомпрометованого агента.

Docker для запуску Hermes не потрібен. Tailscale не використовується. Вхідні порти з інтернету за замовчуванням закриті. Публічні сайти можна публікувати окремо.

## 2. Встановлення та налаштування Hermes

Виконуй від `adminpi`, без sudo:

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
source ~/.bashrc
```

Автозапуск і перевірка

```bash
sudo loginctl enable-linger adminpi
hermes gateway start              # Start the service
hermes gateway status             # Check status
```

Вибір моделі

```bash
hermes model
```

`OpenAI` >> `ChatGPT or Codex Subscription`

Додавання пам’яті для моделі Honcho

```bash
hermes plugins install honcho
hermes memory setup honcho
```

Перезапуск сервісу

```bash
hermes gateway restart
hermes memory status
```
